# 程式審查與優化計畫（2026-10-30）

審查對象：`src/index.html`（commit af1a0bc）。方法：逐行閱讀；依 Artifact runtime contract 0.2.92 的 `db.d.ts` 核對資料庫行為；在暫時的假 `window.claude` 上用 Playwright 開 380px／1280px、淺色／深色截圖；另寫三個重現腳本與一組日期測試。假物件與截圖只在 scratchpad，尚未進 repo。

幾個重要事實先講：
- 檔案是 964 行，不到 1000 行；但很多行極長，換算約 41k tokens，閱讀負擔相當於兩三千行。
- 日期邏輯（台北時區、凌晨 4 點換日、月底加月份、閏年、跨年）9 項測試全部通過，目前沒有問題。

## 四、程式結構

建議**不拆檔、不加建置步驟**。理由：發布流程是「把 `src/index.html` 交給 claude.ai 發布」，多一個 build 就多一個「發布了舊版本或沒 build 的檔案」的風險；README 也明寫沒有建置步驟。問題不在行數，在於很多邏輯擠在同一行、各區塊邊界不清。做法是在同一個檔案裡整理：
- 依段落重排：helpers／日期 → 資料層（寫入佇列、快照）→ 渲染工具 → 今天 → 體重面板 → 各子頁 → 檢查 → 設定 → 啟動。
- 日期函式放在有標記的區塊裡，讓 `dev/` 的測試可以直接抽出來跑，不必複製程式碼。
- 新增一個小的 `setHTML(el, html)`：內容沒變就不動 DOM，焦點在區塊內就延到 blur 後再更新（同時解掉 B3）。
- 所有寫入都經過同一個佇列與錯誤處理。

## 八、修訂（參考 Fable、Sonnet、Opus 三份第二意見）

三份意見全文在同目錄的 `*-consult-{fable,sonnet,opus}.md`。下面是我逐項驗證後採納或不採納的結果。

### 更正我原本的判斷
- **B1 的重現方式有偏差**（Opus）。我原本的假物件在寫入完成後才送出快照；`db.d.ts` 寫明自己的寫入會立即出現在快照裡。我把這個行為補進假物件之後，同一台手機「服藥→月經」連點兩筆都有存，重現不了。B1 仍是高嚴重度，但真正的觸發情境是下面的 N1、另一台裝置先建了當天文件、文件已被刪除。
- **B6 的理由錯了**（Opus）。661 行只有數值真的改變時才設 touched，吸附回同一格不會觸發。B6 降為低，等手機實測再決定要不要改輸入模型。
- **B2 降為低**（三方一致）。你已經在線上使用「今天」畫面，外框應該有補這條規則；一行修正照做。我的基準截圖外框自己加了這條規則，所以截圖本身測不到 B2（Opus N4）。
- **M6 對比實際約 3.7:1**，不是 3.3:1（Opus）。

### 新增問題（已驗證）
- **N1 高：資料載入前就能寫入。** 第一筆快照到達前，按鈕已經可以按。我把首筆快照延遲 1.2 秒，當天已有早上 52.3 kg，此時點服藥：文件被 `set` 整份取代，早上體重消失；服藥劑量寫成內建的 50，不是設定的 75（Sonnet、Opus 獨立發現，我重跑確認）。
- **N2 中：設定會被整份覆蓋。** `saveProfile` 用本機 `profile` 做 `set`。`profile` 還沒載入或監聽失敗（錯誤被吞掉）時，匯出後寫 `lastExport` 會把藥名、劑量洗掉（Opus 已驗證）。
- **N3 中：首頁檢查卡**把「需盡快處理」寫成「已逾期 1 天」，而且排在例行逾期之後（Fable、Sonnet 已驗證；611–614 行）。
- **N4 中：寫入失敗沒有重試**，體重面板在寫入前就關了，失敗只能重撥（Sonnet）。
- **N5 低：**過去日期的週點和大標對「完成」的定義不一致（526 對照 545）。
- **N6 低：**頁面停在前景跨過 04:00 或 18:00 不會重算（Fable、Opus）。
- **N7 低：**唯讀時，運動清單的步進、備註、刪除沒有停用（Fable）。
- B3 補充：Chromium 移除有焦點的輸入框時會觸發 `change`，打到一半的備註會被存成完整備註（Fable）。

### 臨床查證抽查（2026-10-30）
抽查 ATA 2015 Recommendation 23、24。PMC 原站在這個工作環境被網路政策擋住，所以讀的是兩份逐字轉載建議原文的來源：

- ATA 官方授權的 GuidelineCentral 快速參考

兩者內容一致：
- 24A：高度懷疑 6–12 個月。
- 24B：低到中度懷疑可考慮 12–24 個月。
- 24C：>1 cm 的極低懷疑或純囊腫，「若要重做超音波，應 ≥24 個月」，等級是無建議、證據不足。
- 24D：≤1 cm 的極低懷疑與純囊腫，不需例行超音波追蹤。
- 23A：穿刺良性加高度懷疑，12 個月內重做超音波與穿刺。

因此 GPT 對甲狀腺的四點判讀成立：
1. 「無結節」自動排 12 個月沒有 ATA 依據。
2. 頁面寫「>24」應為「≥24」。
3. 極低懷疑漏了 ≤1 cm 不需追蹤的分支。
4. 穿刺良性加高度懷疑的 12 個月是「12 個月內」的上界，不是區間下限，而且要一起做穿刺。

Lung-RADS 0 的感染分支（1–3 個月）、USMSTF 增生性息肉 ≤20 顆、BI-RADS 3 後續追蹤，這次沒有另外查原文。
