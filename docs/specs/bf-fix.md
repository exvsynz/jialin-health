# 體重與體脂的記錄與顯示（規格）

2026-10-31 擬定。狀態：待使用者確認（第 5 節）。資料模型不變：`days/{date}.am|pm = { w, bf, at }`。

## 1. 記錄面板（`#wSheet`）

拿掉「體重／體脂」頁籤，兩個值放在同一個畫面，由上而下：

1. 標題列：「早上」或「晚上」（補登時加日期）。
2. **體重**：維持現在的大數字、提示、刻度尺、−0.1／＋0.1。規則不變：
   - 已記錄：帶這筆的值。
   - 晚上有早上值：帶「早上 + 平常的早晚差」推定值，要撥尺確認才能存。
   - 其他：帶上次量的值，可以直接存（「和上次一樣」）。
   - 第一次：顯示「—」，用鍵盤輸入。
3. **體脂**：較小的數字（約體重的一半）、較矮的刻度尺、−0.1／＋0.1。
   - 這一筆已有體脂：帶它，正常顏色，標「已記」。
   - 沒有：帶預設值（見 5.1），淡色並標「未記」。撥動刻度尺、按 ±，或用鍵盤輸入，才變成「已記」。
   - 從來沒有記過體脂：顯示「— %」與「未記」，不顯示體脂的刻度尺與 ±，用鍵盤輸入。
   - 已記之後，數字旁出現小按鈕「不記」，按了回到「未記」，避免誤觸刻度尺後收不回來（見 5.2）。
4. **儲存鈕**寫明要存什麼：
   - 體脂會存：「記下 48.6 kg・24.5%」。
   - 體脂不存：「記下 48.6 kg（體脂未記）」。
   - 體重沒動、沿用上次值時，開頭照舊是「和上次一樣」。
   - 晚上推定值沒撥尺時，照舊停用並寫「撥尺確認晚上體重」。
5. **儲存規則**：
   - 體脂「已記」：存這個值。
   - 「未記」：不存體脂，這一筆原有的 `bf` 保留，沒有就是 `null`，和現在相同。
   - 只寫這個時段（`am` 或 `pm`），撤銷照舊。
6. **「用鍵盤輸入」**：同時出現兩個欄位（kg、%）。
   - 體脂欄留空：不記體脂。
   - 填了：算「已記」。
   - 範圍照舊：體重 20–200、體脂 3–70。
7. **刻度尺**：兩把各自獨立，各有自己的範圍、捲動位置與「重建時忽略捲動」的狀態。
   - 兩把都設 `touch-action: pan-x`，橫向撥尺不會帶動面板上下捲動。
   - 一把的捲動不會改到另一把的值。
   - 吸附規則照舊：0.1 一格，放手後對齊格線。
8. **版面**：
   - 380 寬無水平捲動。
   - 在 380×667（iPhone SE 大小）時，儲存鈕不用捲動就看得到，含底部安全區（`env(safe-area-inset-bottom)`）。
   - 淺色與深色都要過對比檢查。
9. **點擊數**：每次記錄 ≤3 次：
   - 早上：打開面板、儲存。
   - 晚上：打開面板、撥尺、儲存。
   - 體脂是選填的額外動作，不算在內。

## 2. 體脂一律顯示一位小數

只改顯示，不改存的值：
- 今天頁早／晚格子：「體脂 25.0%」。
- 體重頁「最近紀錄」：「48.6・25.0%」。
- 記錄面板、圖上最後一點的標籤。

找過整頁：其他地方（回診摘要、週報提示詞）沒有顯示體脂。

## 3. 體重頁的體脂圖

- 比照體重圖：
  - 每天早上體脂畫實心點，晚上體脂畫空心點。
  - 早上體脂的 7 日平均線照舊：7 天內至少 2 筆才畫。
- 區塊標題從「體脂（早上 7 日平均）」改成「體脂」，加上和體重圖相同格式的圖例：早上 7 日平均、早上、晚上。
- 期間內完全沒有體脂（早上、晚上都沒有）時，才顯示「這段期間還沒有紀錄」。
  - 現在只畫平均線，所以只有 1 筆時也顯示「沒有紀錄」；這次一併改掉。

## 5. 要你確認的

1. **體脂預設值**：你寫「帶上次的體脂」。現在的程式和體重一樣：
   - 晚上有早上值時，用「早上 + 平常的早晚差」推定。
   - 沒有早上值時，才用上次量的。

   建議**改成一律帶上次量的體脂**（同一時段優先，沒有就用另一時段）：
   - 體脂是選填、淡色顯示，推定值的意義不大。
   - 「上次量的」比較容易理解。
2. **「不記」按鈕**（1.3）：你的需求沒有提到。建議加：撥到體脂刻度尺就算已記，沒有它就收不回來，只能關掉面板重來。
3. **第 4 項（選做）**：「最近紀錄」在 380 寬時「晚」會換行。
   - 原因：日期「2026/10/30（五）」加上早、晚兩段太寬。
   - 建議：日期改成「10/30 五」，用三欄格線（日期／早／晚），月經標記放在日期下方。
   - 這樣 380 寬時三欄能排在一行。
